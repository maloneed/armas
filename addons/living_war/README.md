# Living War — ядро кампании

Это первый изолированный модуль Living War для подключения поверх совместимой миссии Antistasi.

## Что реализовано

Сервер хранит единое состояние кампании в `missionNamespace` и публикует его клиентам как read-only snapshot. Состояние содержит версию, последовательность событий, районы и последние 100 событий журнала. Изменения выполняются только через `LW_fnc_applyEvent`, что создаёт единую точку интеграции для захвата районов, потерь, диверсий, конвоев и гражданских инцидентов.

Состояние сохраняется в `profileNamespace` после каждого события и восстанавливается при старте сервера. Если сохранения нет, создаётся район `default` с нейтральными начальными значениями.

## Подключение

Добавьте каталог `addons/living_war` в сборку аддона или миссии и убедитесь, что путь `living_war\\functions` доступен из PBO. На первом этапе модуль не создаёт юнитов и не меняет базовую кампанию Antistasi.

## Пример события

```sqf
[
    "CAPTURE",
    "town_alpha",
    createHashMapFromArray [
        ["delta", createHashMapFromArray [
            ["pressure", -15],
            ["support", 10],
            ["supply", 5]
        ]]
    ]
] call LW_fnc_applyEvent;
```
