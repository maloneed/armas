LIVING WAR — ПРОСТАЯ УСТАНОВКА

1. Закройте Arma 3.
2. Распакуйте папку @LivingWar в папку игры Arma 3.
   Внутри папки игры должен появиться путь:
   Arma 3\@LivingWar\addons\living_war.pbo
3. Запустите Arma 3 Launcher.
4. Откройте Локальные моды и добавьте папку @LivingWar.
5. Поставьте галочку напротив Living War.
6. В Workshop подпишитесь на совместимую версию Antistasi Community.
7. Включите Antistasi и Living War одновременно.
8. Нажмите ИГРАТЬ -> Новая игра -> Хостить сервер.
9. Выберите миссию Antistasi для вашей карты.
10. После запуска при желании откройте debug-панель администратора:

   call LW_fnc_openDebugUI;

Для первого запуска параметры Living War уже имеют безопасные значения по умолчанию.
Мод не является самостоятельной миссией: сначала должна быть загружена Antistasi.

Для сервера Dedicated используйте ту же папку @LivingWar и параметр запуска:

   -mod=@Antistasi;@LivingWar

Для локальной игры в лаунчере достаточно поставить галочки Antistasi и Living War.
