# Living War

Модульная надстройка над совместимой миссией Antistasi для Arma 3. Проект хранит состояние кампании на сервере и реагирует на игровые события, не заменяя базовую миссию.

## Быстрая установка

GitHub Actions собирает ZIP-архив при каждом изменении ветки `main`. Скачайте artifact `LivingWar-<commit>.zip`, распакуйте каталог `@LivingWar` в папку сервера и запустите сервер с параметром:

```text
-mod=@LivingWar
```

Модуль не создаёт собственную миссию. Он подключается к миссии Antistasi как изолированный аддон; фактические адаптеры Antistasi будут добавляться отдельными версиями.

## Сборка локально

Для сборки без сторонних PBO-инструментов:

```bash
./build_mod.sh
```

Результат появится в `dist/@LivingWar`. Для запуска на сервере нужен совместимый Antistasi и обычная конфигурация сервера.

## Текущее API

- `LW_fnc_getState` — получить опубликованный snapshot состояния.
- `LW_fnc_getDistrict` — получить состояние одного района.
- `LW_fnc_getSummary` — получить лёгкую сводку районов.
- `LW_fnc_registerDistrict` — зарегистрировать район на сервере.
- `LW_fnc_applyEvent` — применить событие и сохранить состояние.
- `LW_fnc_getConfig` — получить настройки модуля.

Пример события:

```sqf
[
    "CAPTURE",
    "town_alpha",
    createHashMapFromArray [
        ["delta", createHashMapFromArray [
            ["pressure", -15],
            ["support", 10],
            ["supply", 5]
        ]]
    ]
] call LW_fnc_applyEvent;
```

## Ограничения текущей версии

Сейчас модуль предоставляет фундамент состояния и сохранения. Подключение конкретных событий Antistasi, интерфейс командира и директор войны ещё не реализованы. Перед эксплуатацией на боевом сервере протестируйте сохранение на копии профиля сервера.
