# Радиосреда и задачи лагерей

## Радиопереговоры

Серверная функция `LW_fnc_radioTick` периодически выбирает зарегистрированные лагеря/КПП/базы и отправляет близким клиентам короткие русские реплики о снабжении, потерях, разведке, патрулях и событиях на фронте. Дальность слышимости — 1800 метров, громкость уменьшается с расстоянием.

По умолчанию используется `playSoundUI ["Hint", ...]` как безопасный звуковой сигнал и русский текст в системном чате. Для настоящих радио-файлов задайте клиентский hook:

```sqf
LW_radioSoundHook = {
    params ["_prefix", "_speaker", "_text", "_position", "_volume"];
    // Подключите собственный soundCfg или playSound3D вашей версии мода.
};
```

Отключение:

```sqf
private _cfg = profileNamespace getVariable ["LW_config", createHashMap];
_cfg set ["radioEnabled", false];
profileNamespace setVariable ["LW_config", _cfg];
saveProfileNamespace;
```

## Интерфейс лагеря

Зарегистрированный лагерь можно открыть на клиенте:

```sqf
["camp_alpha"] call LW_fnc_openCampUI;
```

Окно показывает назначение системы, категории задач, кнопку получения случайной задачи и русские уведомления с описанием и наградой.

## Каталог

Каталог содержит 20 задач: набор добровольцев, сопровождение новобранцев, освобождение пленных, эвакуация раненых, рейд на кассу, долг контрабандиста, саботаж военной кассы, удар по нефтебазе, разрыв железной дороги, сбой на военном заводе, захват оружейной, охота на офицера, ночной сброс, тайник наблюдателя, перехват радиосети, возврат карт, срыв работы КПП, засада на снабжение, листовки сопротивления и пополнение лагеря.

Каждая задача имеет категорию, описание и числовые награды за `manpower`, `money`, `eliteGear`, а также `economyDamage` для нанесения ущерба экономике противника.

Выдать случайную задачу программно:

```sqf
[player, "camp_alpha"] call LW_fnc_offerMission;
```

Завершить задачу серверным кодом после выполнения условий миссии:

```sqf
["fuel_depot", "town_alpha"] call LW_fnc_completeMission;
```

Фактические условия выполнения — уничтожение объекта, доставка груза, спасение пленных и т.п. — подключаются миссией Antistasi к этому API. Каталог и награды не зависят от конкретного способа проверки цели.
