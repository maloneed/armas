# Тестирование Living War на сервере

## Установка

Скопируйте `release/@LivingWar` в корень сервера и добавьте `-mod=@LivingWar` к параметрам запуска. Запускайте совместимую миссию Antistasi как обычно.

## Автоназначение ролей

Зарегистрируйте район с позицией и угрозой:

```sqf
["town_alpha", createHashMapFromArray [
    ["position", getPosATL player],
    ["threat", 80],
    ["supply", 60]
]] call LW_fnc_registerDistrict;
```

Запустите назначение:

```sqf
private _assigned = call LW_fnc_assignAIRoles;
diag_log format ["LW назначено ролей: %1", count _assigned];
```

Проверьте переменные на AI-группе:

```sqf
_group getVariable ["LW_antistasiRole", "UNASSIGNED"];
_group getVariable ["LW_districtId", ""];
```

Группа игрока, группа с активным `LW_directorOrder` и группа с уже назначенной ролью не изменяются.

## Русская debug-панель

На клиенте администратора:

```sqf
call LW_fnc_openDebugUI;
```

Окно обновляется раз в секунду. Оно показывает состояние районов и активные роли/приказы всех видимых групп. Закрыть:

```sqf
call LW_fnc_closeDebugUI;
```

Обычный игрок должен получить сообщение об отсутствии доступа.

## Smoke-тест ядра

```sqf
call LW_fnc_runSmokeTest;
```

Ожидаемый результат: `Living War smoke test: PASS`.

## Что проверять в RPT

Ищите записи `[Living War]`. После автоназначения должна появиться запись о количестве назначенных существующих AI-групп. Новые группы при этом не создаются.

## Автоинициализация и диагностический отчёт

Через 15 секунд после старта сервер автоматически обнаруживает стороны, существующие AI-группы и районы. Повторная проверка выполняется раз в 60 секунд. Система только добавляет supplemental metadata и не создаёт, не удаляет и не телепортирует группы.

Автотест запускается при старте и раз в пять минут. Для ручного запуска:

```sqf
private _report = call LW_fnc_runAutoTest;
call LW_fnc_exportAutoTest;
```

Ищите в RPT блоки `[Living War][AUTOTEST]`. Последний структурированный отчёт доступен как `LW_lastAutoTest` и сохраняется в `profileNamespace`. Загрузите RPT вместе со скопированным блоком для последующего анализа.

## Ограничения

Автоназначение требует координат районов. Hook конкретной версии Antistasi остаётся на стороне миссии, поскольку внутренние функции AI различаются между сборками.
